# LiveAutomation-SeleniumJava

A test automation framework developed using Java, Selenium WebDriver, TestNG, and Maven for automating web application testing. The framework supports reusable test cases, efficient test execution, and report generation to improve software quality and reduce manual testing effort.

## Tech Stack

- Java
- Selenium WebDriver
- TestNG
- Maven

## Features

- Automated Web UI Testing
- Reusable Test Cases
- TestNG Test Execution
- Maven Dependency Management
- Automated Test Reports
- Scalable Framework Structure
